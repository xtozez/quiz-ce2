# 🎉 Le Grand Quiz du CE2

## Les fichiers
| Fichier | À quoi il sert |
|---|---|
| `index.html` | La page du jeu (télé ET téléphone) |
| `questions.js` | ✏️ **La liste des questions : c'est ici que vous modifiez ou ajoutez des questions** |
| `jeu.js` | Le fonctionnement du jeu (pas besoin d'y toucher) |
| `style.css` | Les couleurs et la mise en page |

## Mettre le jeu en ligne (une seule fois, gratuit)
1. Créez un compte gratuit sur **github.com** (Sign up).
2. En haut à droite : **+** → **New repository**. Nom : `quiz-ce2`. Cochez **Public**. Cliquez **Create repository**.
3. Sur la page suivante, cliquez le lien **uploading an existing file**.
4. Glissez les 4 fichiers (`index.html`, `questions.js`, `jeu.js`, `style.css`) dans la page, puis **Commit changes**.
5. Allez dans **Settings** → **Pages** (menu de gauche).
   Dans « Branch », choisissez **main** puis **/(root)** et cliquez **Save**.
6. Attendez 1 à 2 minutes et rechargez la page : l'adresse du jeu apparaît en haut, du type
   `https://votre-nom.github.io/quiz-ce2/`. Notez-la !

**Modifier les questions plus tard :** sur GitHub, cliquez `questions.js` → l'icône ✏️ (crayon) → modifiez → **Commit changes**. Le site est mis à jour en 1 à 2 minutes.

## Lancer une partie
1. Sur l'ordinateur branché à la télé, ouvrez l'adresse du jeu (Chrome ou Edge conseillés).
2. Cliquez une fois n'importe où sur l'écran : ça active le **son** et le **plein écran** (touche **F** pour entrer/sortir du plein écran).
3. Sur votre téléphone, ouvrez l'appareil photo et **scannez le QR code** affiché à la télé. Ouvrez le lien.
4. Le téléphone affiche « 🟢 Connecté à la télé ». Écrivez les noms des équipes, choisissez le nombre de questions, puis **▶️ Commencer la partie**.
5. Pendant le jeu :
   - une équipe tape sur la sonnette → appuyez sur **🔴 Rouge a sonné** ou **🔵 Bleu a sonné** ;
   - **✅ Bonne réponse** : l'équipe gagne les points ;
   - **❌ Mauvaise réponse** : la parole passe à l'autre équipe (si elle se trompe aussi, personne ne gagne) ;
   - **📺 Montrer la réponse à la télé**, puis **⏭️ Question suivante**.
   - En cas d'erreur : **✏️ Corriger les points** (+1 / −1).
6. À la fin : écran du gagnant avec confettis. En cas d'égalité : **⭐ Poser une question bonus**.

## Si ça coupe
- Le téléphone se reconnecte tout seul (bandeau orange « Reconnexion… » puis vert). Les scores sont gardés par la télé.
- Si vous fermez le navigateur du téléphone : rescannez le QR code (il apparaît en petit dans le coin de la télé quand le téléphone est déconnecté).
- Si la page de la télé est rechargée, la partie reprend où elle en était.

## Bon à savoir
- Il faut **Internet** sur l'ordinateur et le téléphone (le mieux : le même Wi-Fi).
- Le jeu retient les questions déjà posées **sur cet ordinateur**. Pour tout remettre : sur le téléphone, **⚙️ Réglages** → **♻️ Remettre toutes les questions**.
